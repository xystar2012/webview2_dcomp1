Composition Demo

This page is composited by DirectComposition over a native child window. The 648x338 rectangle in the middle is a real hole in this page - the moving GIF you see through it is drawn by the layer underneath, not by the browser.

Top layer - WebView2

Everything on the ring: this text, the cards and the gradient.

  • DComp target: BrowserWnd
  • Bounds mode: RAW_PIXELS
  • Rasterization scale: 1.0
  • Default background: {0,0,0,0}

Controls placed inside the cut-out are not clickable: BrowserWnd forwards those points straight to VideoWnd. Put controls outside the cut-out, like this card.

Bottom layer - VideoWnd

An animated GIF on an ID2D1HwndRenderTarget, in a child HWND below this visual.

  • Frames: 110
  • Cadence: ~60 Hz
  • Drawn 1:1 inside the cut-out

Because the WebView2 visual is transparent inside the cut-out, DirectComposition lets the GIF through - pixel for pixel.

Click test

These buttons sit outside the cut-out, so pointer events reach the WebView2 and the page handles them.
